# 📦 Estoque System

Sistema de gerenciamento de estoque desenvolvido em Java com o objetivo de praticar conceitos de Programação Orientada a Objetos (POO).

## 🚀 Sobre o projeto

O Estoque System é uma aplicação simples para controle de produtos, permitindo cadastrar, listar e gerenciar informações de estoque.

O projeto foi desenvolvido para aplicar conceitos fundamentais do desenvolvimento back-end utilizando Java.

## 🛠 Tecnologias utilizadas

- Java 17+
- Programação Orientada a Objetos (POO)
- IntelliJ IDEA
- Git e GitHub

## 📚 Conceitos aplicados

- Classes e Objetos
- Encapsulamento
- Construtores
- Métodos
- ArrayList
- Interfaces
- Organização de pacotes

## ⚙️ Funcionalidades

Atualmente o sistema possui:

✅ Cadastro de produtos  
✅ Listagem de produtos  
✅ Controle de quantidade em estoque  
✅ Estrutura organizada em pacotes Java

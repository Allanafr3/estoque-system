# 📦 Estoque System

Sistema de gerenciamento de estoque desenvolvido em Java com o objetivo de praticar conceitos de Programação Orientada a Objetos (POO).

## 🚀 Sobre o projeto

O Estoque System é uma aplicação simples para controle de produtos, permitindo cadastrar, listar, excluir, editar e gerenciar informações de estoque.

O projeto foi desenvolvido para aplicar conceitos fundamentais do desenvolvimento back-end utilizando Java.

## 🛠 Tecnologias utilizadas

- Java 17+
- Programação Orientada a Objetos (POO)
- IntelliJ IDEA
- Git e GitHub
- MySQL

## 📚 Conceitos aplicados

- Classes e Objetos
- Encapsulamento
- Construtores
- Métodos
- ArrayList
- Interfaces
- Organização de pacotes
- JDBC e MAVEN

## ⚙️ Funcionalidades

Atualmente o sistema possui:

✅ Cadastro de produtos  
✅ Listagem de produtos  
✅ Edição de produtos
✅ Exclusão de produtos
✅ Ações salvas no MySQL
✅ Estrutura organizada em pacotes Java
